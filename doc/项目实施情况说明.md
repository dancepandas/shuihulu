# 水葫芦智能识别系统 — 项目实施情况说明

## 一、项目概述

本项目面向河道水葫芦入侵监测需求，采用深度学习技术实现水葫芦的自动检测与像素级分割，替代传统人工巡查方式，为河道管理部门提供高效、客观的监测手段。系统已完成核心算法研发、模型训练与部署验证，具备实际应用能力。

## 二、核心算法原理

### 2.1 两阶段组合检测分割方案

本系统采用 **YOLOv8-seg + SAM** 两阶段级联架构，兼顾检测速度与分割精度：

**第一阶段 — YOLOv8-seg 目标检测：**
- 基于YOLOv8实例分割模型，对输入图像进行快速推理，定位水葫芦目标并输出边界框坐标
- 模型结构由Backbone（C2f模块提取多尺度特征）、Neck（FPN+PAN特征金字塔融合）、Head（Anchor-Free解耦检测头）组成
- 借鉴YOLACT并行分割思路，在检测的同时输出粗粒度分割掩膜

**第二阶段 — SAM 精细分割：**
- 将YOLOv8输出的边界框作为提示（Prompt）输入Meta AI发布的SAM（Segment Anything Model）大模型
- SAM基于ViT-H图像编码器提取全局特征，通过Mask Decoder生成像素级精细掩膜
- 利用SAM零样本学习能力，无需针对水葫芦场景重新训练即可实现高质量分割
- 相比YOLOv8原生分割头，SAM分割边缘更精细，能更好剔除岩石、水体、杂草等干扰


### 2.2 算法流程

```
河道监控图像/视频帧
    ↓
YOLOv8-seg 推理（640×640，置信度阈值0.25，NMS IoU阈值0.5）
    ↓
输出 N 个目标边界框 [x1, y1, x2, y2]
    ↓
SAM ViT-H：逐框输入边界框提示 → 生成像素级掩膜
```

## 三、模型训练与优化策略

### 3.1 数据集

- 从河道监控视频中筛选514张水葫芦图像，覆盖日间、夜间、光照不足等多种场景
- 包含小、中、大三种尺寸水葫芦目标，确保模型对不同尺度目标的适应性
- 采用SAM辅助标注：加载SAM预训练模型（ViT-H版本），通过点提示方式快速标注，生成COCO格式数据集；使用Roboflow修正标注掩膜异常节点，提升标注质量
- 按8:2比例划分为训练集与验证集

### 3.2 训练优化策略

| 策略 | 说明 |
|------|------|
| **COCO迁移学习** | 加载YOLOv8-seg在COCO数据集的预训练权重，在小样本场景下加速收敛、提升精度 |
| **FPN P3层冻结** | 冻结特征金字塔中P3层（小目标检测层）权重，防止小样本过拟合，保留预训练特征 |
| **遗传算法超参优化** | 对学习率、动量、权重衰减、增强参数等进行300次迭代变异搜索，自动寻找最优超参组合 |
| **13种数据增强** | 色相/饱和度/明度调整、旋转、平移、马赛克、复制粘贴、RandAugment、擦除、翻转、缩放等，扩充数据多样性 |
| **早停机制** | 连续50轮mAP无提升则自动停止训练，防止过拟合 |
| **SGD优化器** | 动量0.937，基础学习率0.01 |

### 3.3 训练配置

- 基础模型：YOLOv8m-seg（中等规模，速度与精度平衡）
- 输入尺寸：640×640
- 训练轮数：100轮（含早停）
- SAM模型：ViT-H版本（2.4GB，最高精度）

## 四、模型已搭建完成及识别成果

### 4.1 水葫芦检测模型

模型已完成训练与验证，核心指标如下：

| 指标 | 数值 |
|------|------|
| **检测精度 Precision(B)** | 86.8% |
| **检测召回率 Recall(B)** | 81.2% |
| **mAP50(B)** | 87.5% |

| **分割召回率 Recall(M)** | 72.4% |

## 五、技术优势总结

1. **精度与速度兼顾**：YOLOv8快速定位 + SAM精细分割，两阶段级联实现高精度像素级分割
2. **零样本泛化**：SAM无需领域重训练即可适配新场景，降低部署成本
3. **小样本优化**：迁移学习 + P3冻结 + 遗传算法超参优化，有效解决水葫芦样本量有限的问题
4. **端到端自动化**：从图像输入到识别输出全流程自动化，直接服务于河道管理决策
