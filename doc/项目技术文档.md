# 水葫芦面积识别系统 — 项目完整技术文档

## 一、项目背景与目标

### 1.1 问题背景

水葫芦（水风信子）是一种入侵性水生植物，繁殖速度极快，会覆盖水面、阻塞河道、破坏生态平衡。河道管理部门需要实时监测水葫芦的覆盖面积，以便制定打捞计划。传统人工巡查效率低、主观性强，因此需要一种自动化的视觉检测方案。

### 1.2 论文方案

本系统复现自论文《基于YOLOv7的水葫芦目标检测方法研究》（王天昊）中的核心方案——**YOLOv8 + SAM 两阶段组合模型**，用于水葫芦的像素级实例分割与面积估算。

核心思路：

```
YOLOv8-seg（目标检测，输出边界框）→ SAM（零样本精细分割，输出像素掩膜）→ 面积估算
```

为什么不直接用 YOLOv8-seg 自带的分割头？

| 方面 | YOLOv8-seg 原生分割 | YOLOv8 + SAM 组合方案 |
|------|---------------------|----------------------|
| 分割精度 | 中等，边缘粗糙 | 高，边缘精细 |
| 速度 | 快（单阶段） | 稍慢（两阶段） |
| 小目标分割 | 较差 | SAM 零样本能力提升小目标分割 |
| 干扰剔除 | 易受岩石/水体干扰 | SAM 能更好剔除干扰 |

结论：用 YOLOv8 做快速定位，SAM 做精细分割，兼顾速度与精度。

## 五、核心模块详解：`YoloSamPipeline`

这是整个系统的核心类，位于 `src/shuihulu_yolo_sam/model.py`。

### 5.1 类初始化

```python
pipeline = YoloSamPipeline(
    yolo_model_path="weights/yolov8n-seg.pt",  # YOLOv8 权重
    sam_checkpoint="weights/sam_vit_h.pth",     # SAM 权重
    sam_model_type="vit_h",                     # SAM 架构类型
    device=0,                                   # GPU 编号，-1 为 CPU
)
```

初始化流程：
1. 解析 device（`int` → `"cuda:0"` 或 `"cpu"`）
2. 加载 YOLOv8 模型（`ultralytics.YOLO`）
3. 加载 SAM 模型（`segment_anything.sam_model_registry` → `SamPredictor`）
4. 将 SAM 模型移至指定设备

### 5.2 第一步：YOLOv8 检测 — `detect()`

```python
results, boxes_xyxy = pipeline.detect(
    image="test.jpg",   # 图片路径或 numpy 数组
    conf=0.25,          # 置信度阈值
    iou=0.5,            # NMS IoU 阈值
    imgsz=640,          # 输入图像尺寸
)
```

**输入**：RGB 图像（路径或 numpy 数组）

**输出**：
- `results`：ultralytics 原始 Results 对象（含 boxes、masks、probs 等）
- `boxes_xyxy`：`torch.Tensor`，形状 `(N, 4)`，N 个检测框的坐标 `[x1, y1, x2, y2]`

**内部流程**：
```
原始图像 → YOLOv8-seg 推理 → NMS 后处理 → 输出边界框坐标
```

### 5.3 第二步：SAM 精细分割 — `segment()`

```python
masks, scores = pipeline.segment(
    image_rgb=image_rgb,   # HWC uint8 RGB numpy 数组
    boxes_xyxy=boxes_xyxy, # (N,4) 边界框
)
```

**输入**：
- `image_rgb`：HWC 格式 uint8 RGB 图像
- `boxes_xyxy`：YOLOv8 输出的边界框

**输出**：
- `masks`：`list[np.ndarray]`，每个元素为 `(H, W)` 的 bool 掩膜
- `scores`：`list[float]`，每个掩膜的 SAM 置信度

**内部流程**：
```
1. SAM 编码器提取图像特征（set_image）
2. 对每个边界框：
   a. 将边界框作为提示输入 SAM 解码器
   b. predict(box=box, multimask_output=False) → 单掩膜
   c. 收集掩膜与置信度
```

关键参数 `multimask_output=False`：SAM 默认输出 3 个掩膜供选择，设为 False 只输出 1 个最佳掩膜。因为我们提供了边界框提示，SAM 能确定唯一目标，无需多掩膜选择。

### 5.4 完整两阶段推理 — `predict()`

```python
results, masks, scores = pipeline.predict(
    image="test.jpg",
    conf=0.25,
    iou=0.5,
    imgsz=640,
)
```

这是 `detect()` + `segment()` 的串联封装。如果 YOLOv8 没检测到目标（`boxes_xyxy` 为空），直接返回空列表。

### 5.5 面积估算 — `estimate_area()`

```python
# 像素面积
area_px = pipeline.estimate_area(masks)

# 实际面积（需知道每米对应多少像素）
area_m2 = pipeline.estimate_area(masks, pixels_per_meter=100.0)
```

**原理**：
- 掩膜是 `(H, W)` 的 bool 数组，`True` 表示水葫芦像素
- `m.sum()` = 水葫芦像素数
- 若提供 `pixels_per_meter`（P），则实际面积 = 像素数 / P²

**如何确定 pixels_per_meter？**

需要在拍摄场景中放置标定物（或已知尺寸参照物），计算：
```
pixels_per_meter = 图片中参照物的像素长度 / 参照物实际长度(米)
```

### 5.6 可视化 — `visualize()`

```python
overlay = pipeline.visualize(
    image_rgb=image_rgb,       # 原图 RGB
    masks=masks,               # 掩膜列表
    boxes_xyxy=boxes_xyxy,     # 边界框（可选）
    alpha=0.5,                 # 掩膜透明度
    color=(0, 255, 0),         # 掩膜颜色（BGR 绿色）
)
```

**效果**：在原图上叠加半透明绿色掩膜 + 绿色边界框。

## 六、训练模块详解

### 6.1 训练策略概览

论文的训练策略针对 **YOLOv8-seg**（第一阶段），SAM 不需要训练（零样本）。

```
COCO 预训练权重 → 冻结 FPN P3 层 → SGD 微调 100 轮 → 可选遗传算法优化
```

### 6.2 为什么冻结 FPN P3 层？

YOLOv8-seg 的 Neck 结构：

```
Backbone (C2f 特征提取)
    ↓
Neck (FPN + PAN 特征融合)
    ├── P3 层（检测小目标，80×80 特征图）
    ├── P4 层（检测中目标，40×40 特征图）
    └── P5 层（检测大目标，20×20 特征图）
    ↓
Head (Anchor-Free 解耦检测头)
```

冻结 P3 层的原因：
- 水葫芦数据集仅 514 张，属于小样本
- P3 层在 COCO 上已学到良好的底层特征（边缘、纹理等）
- 冻结 P3 减少可训练参数，防止小样本过拟合
- 加快收敛速度

### 6.3 冻结 P3 的实现

`model.py:freeze_fpn_p3()`：

```python
def freeze_fpn_p3(model: YOLO) -> None:
    for name, param in model.model.named_parameters():
        layer_idx = name.split(".")[1] if name.startswith("model.") else ""
        if layer_idx in {"10", "13"}:
            param.requires_grad = False
```

YOLOv8-seg 内部层编号：
- 层 0-9：Backbone（C2f 等）
- 层 10：Neck 中处理 P3 特征的 Upsample + Concat 层
- 层 11-12：Neck 中 P4 相关层
- 层 13：Neck 中 P3 的最终 Concat 层
- 层 14+：Head

所以 `layer_idx in {"10", "13"}` 精确匹配了 P3 相关的 Neck 层。

### 6.4 训练脚本 — `train_yolo_sam.py`

```bash
python scripts/train_yolo_sam.py \
  --model weights/yolov8n-seg.pt \
  --data configs/dataset_hyacinth_seg.yaml
```

**参数详解**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--model` | 必填 | COCO 预训练 YOLOv8-seg 权重路径 |
| `--data` | `configs/dataset_hyacinth_seg.yaml` | 数据集配置 |
| `--epochs` | 100 | 训练轮数（论文值） |
| `--imgsz` | 640 | 输入图像尺寸（论文值） |
| `--batch` | 8 | 批大小 |
| `--patience` | 50 | 早停耐心轮数（论文值） |
| `--device` | 0 | GPU 编号 |
| `--no-freeze-p3` | False | 不冻结 P3 层 |
| `--tune` | False | 训练后执行遗传算法超参搜索 |
| `--tune-iterations` | 300 | 遗传算法迭代次数 |

**训练流程**：

```
1. 加载 COCO 预训练权重
2. 冻结 FPN P3 层（除非 --no-freeze-p3）
3. SGD 优化器微调 100 轮
   ├── 每个 epoch: 前向传播 → 计算损失 → 反向传播 → 更新非冻结层
   ├── 验证集评估 mAP
   └── patience=50：连续 50 轮 mAP 不提升则早停
4. 保存最优权重到 runs/segment/hyacinth_yolo_sam/weights/best.pt
5. 可选：遗传算法超参搜索（--tune）
```

### 6.5 遗传算法超参数优化

```bash
python scripts/train_yolo_sam.py \
  --model weights/yolov8n-seg.pt \
  --data configs/dataset_hyacinth_seg.yaml \
  --tune --tune-iterations 300
```

Ultralytics 内置的遗传算法优化：
- 对初始学习率、动量、权重衰减、图像增强参数等进行迭代变异
- 每次迭代训练一小段，评估适应度
- 最终输出最优超参数组合

## 八、验证模块详解

### 8.1 运行验证

```bash
python scripts/val_yolo_sam.py \
  --yolo-model runs/segment/hyacinth_yolo_sam/weights/best.pt \
  --sam-checkpoint weights/sam_vit_h.pth \
  --data configs/dataset_hyacinth_seg.yaml
```

### 8.2 验证流程

```
1. 读取数据集配置，定位验证集图片和标签目录
2. 初始化 YoloSamPipeline
3. 对每张验证图片：
   a. YOLOv8 + SAM 两阶段推理 → 预测掩膜
   b. 合并所有预测掩膜 → combined_pred (H,W) bool
   c. 读取 YOLO 格式标签 → 解析多边形 → 渲染为 GT 掩膜 → combined_gt (H,W) bool
   d. 计算 IoU = intersection / union
4. 汇总统计 Mean/Min/Max IoU
```

### 8.3 IoU 计算

```python
IoU = (预测掩膜 ∩ 标注掩膜) / (预测掩膜 ∪ 标注掩膜)
```

注意：这里将同一张图的所有目标掩膜合并为一个整体掩膜再计算 IoU，衡量的是全局分割质量。


## 十二、完整使用流程（从零开始）

### Step 1：环境搭建

```bash
conda create -n shuihulu python=3.10
conda activate shuihulu
pip install -r requirements.txt
```

### Step 2：下载权重

```bash
python scripts/download_weights.py --model yolov8n-seg.pt

```

### Step 3：准备数据集

将水葫芦图片和标签按 Ultralytics 格式放入 `datasets/hyacinth_seg/`，修改 `configs/dataset_hyacinth_seg.yaml`。

```bash
python scripts/train_yolo_sam.py \
```

```bash
  --sam-checkpoint weights/sam_vit_h.pth \
  --data configs/dataset_hyacinth_seg.yaml
```

## 十三、性能优化建议

1. **GPU 显存不足**：换用更小的模型（`yolov8n-seg.pt` + `sam_vit_b.pth`）或减小 `batch`
2. **推理速度慢**：SAM ViT-H 编码器是瓶颈，可换 `sam_vit_b` 提速 3-5 倍
3. **精度不够**：换用更大的 YOLO（`yolov8m-seg.pt`）或增加训练轮数
4. **小目标检测差**：降低 `conf` 阈值（如 0.1），增大 `imgsz`（如 960）
5. **端侧部署**：YOLOv8 可导出 ONNX/TensorRT，SAM 可考虑 TinySAM 蒸馏
